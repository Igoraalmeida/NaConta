# 📊 NaConta — Gestão Financeira Simplificada

O **NaConta** é uma aplicação web intuitiva e moderna desenvolvida para ajudar na gestão e controlo financeiro pessoal. Com uma interface limpa e responsiva, permite registar receitas e despesas em tempo real, organizar lançamentos por categoria e visualizar o saldo consolidado de forma transparente.

🚀 **Aceda à aplicação:** [naconta.online](https://naconta.online) *(ou na-conta.vercel.app)*

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web fundamentais, focando em desempenho, semântica e manipulação limpa do DOM:

- **HTML5:** Estruturação semântica e acessível.
- **CSS3:** Estilização moderna utilizando CSS Grid, Flexbox e variáveis CSS para garantir total responsividade.
- **JavaScript (ES6+):** Manipulação dinâmica do DOM, gestão de estado em array e cálculos automáticos de saldo.

---

## ✨ Funcionalidades

- ➕ **Registo de Transações:** Adição rápida de receitas e despesas com campo de data, descrição, valor e categoria.
- 🏷️ **Categorização:** Organização de lançamentos com badges visuais dinâmicos.
- 📈 **Cálculo Automático:** Atualização instantânea dos totais de entradas, saídas e saldo líquido.
- 📱 **Design Responsivo:** Layout adaptado para dispositivos móveis, tablets e computadores.
- 🎨 **Interface Intuitiva:** Dashboard moderno focado na usabilidade e experiência do utilizador.
